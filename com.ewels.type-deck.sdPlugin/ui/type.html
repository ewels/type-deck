Finish keys
 Each step is one key press, run in order. Click "Record" on a step and press the keys you want, or type the combo in by hand as modifiers plus a key name joined with + (for example meta+shift+enter). Modifier names are control, alt, shift and meta (Command on macOS, Windows key elsewhere). A few system shortcuts are swallowed by the OS and cannot be recorded, so type those in. How long to wait before each step. Give a step its own number to override it, for example to wait for a dialog to open before the next press.
Instant type
Pastes the whole text via the system clipboard (your previous clipboard contents are restored). Good for large texts.
