Lines
Each non-empty line is typed in turn. First press types line 1, next press line 2, etc., looping back to the start. Template variables: {date} = YYYY-MM-DD, {time} = HH:MM:SS, {clipboard} = current clipboard text, {counter} = press count. Use {{ and }} for literal braces.
Finish key
 Click "Record combo" and press the keys you want, for example Return or Cmd+Shift+Return. A few system shortcuts are swallowed by the OS and cannot be recorded: those can be typed into the field by hand, as modifiers plus a key name joined with + (for example meta+shift+enter). Modifier names are control, alt, shift and meta (Command on macOS, Windows key elsewhere). How long to wait after the last character before pressing the combo.
Instant type
Pastes the whole text via the system clipboard (your previous clipboard contents are restored). Good for large texts.
Safety
If unchecked, pressing again will queue another message.
